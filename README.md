# Academic Board Exam Portal

এটি একটি স্ট্যাটিক সিঙ্গেল-পেজ ওয়েব অ্যাপ (HTML, CSS, Vanilla JS) যা শিক্ষার্থীদের সেমিস্টার ট্র্যাকিং এবং পরীক্ষার প্রস্তুতির জন্য তৈরি করা হয়েছে। 

## 🚀 বর্তমান রিলিজ এবং ভার্সন

* **Current Version:** `v1.1.0` (Static Frontend)
* **Development Tag:** `v1.2.0-dev`
* **Branch Structure:**
  * `main` - প্রোডাকশন রেডি স্ট্যাটিক ভার্সন (v1.1.0)
  * `development` - ভবিষ্যৎ ডেভলপমেন্ট এবং নেক্সট.জেএস (Next.js) মাইগ্রেশনের জন্য তৈরি ব্রাঞ্চ

## 🛠️ গিট ও ভার্সন কন্ট্রোল গাইডলাইন

ভবিষ্যতে যেকোনো ভার্সন বা ব্রাঞ্চে যাওয়ার জন্য নিচের কমান্ডগুলো ব্যবহার করতে পারেন:

**ডেভলপমেন্ট ব্রাঞ্চে যেতে:**
```bash
git checkout development
```

**মেইন ব্রাঞ্চে যেতে:**
```bash
git checkout main
```

**নির্দিষ্ট ট্যাগ বা ভার্সনে সুইচ করতে (যেমন: v1.1.0 বা v1.2.0-dev):**
```bash
git checkout v1.1.0
```
*(বিঃদ্রঃ ট্যাগে সুইচ করলে এটি detached HEAD স্টেটে থাকে। আগের কোনো ভার্সন থেকে নতুন আপডেট শুরু করতে চাইলে `git checkout -b new-branch-name v1.1.0` ব্যবহার করুন।)*

## 🌐 ভবিষ্যৎ পরিকল্পনা (Next.js Full-Stack Migration)

এই প্রজেক্টটি ভবিষ্যতে **React ও Next.js** ব্যবহার করে ফুল-স্ট্যাক অ্যাপ্লিকেশনে কনভার্ট করা হবে। মাইগ্রেশনের সময় নিচের বিষয়গুলো ধাপে ধাপে সম্পন্ন করা হবে:

1. **Frontend Architecture:** বর্তমান Vanilla JS এবং HTML কে React Components (Next.js App Router/Pages Router)-এ রূপান্তর করা হবে। বর্তমান CSS-কে মডিউলার করে ব্যবহার করা হবে অথবা TailwindCSS এ মাইগ্রেট করা হবে।
2. **State Management:** বর্তমানে `localStorage` ব্যবহার করা হচ্ছে। ভবিষ্যতে React Context API, Redux, অথবা Zustand ব্যবহার করা হবে ডেটা হ্যান্ডেল করার জন্য।
3. **Backend & Database:** ইউজারদের নিজস্ব প্রশ্ন এবং ডেটা সেন্ট্রালি সেভ করার জন্য অনলাইন ডেটাবেস (MongoDB, PostgreSQL বা Firebase) যুক্ত করা হবে। API Routes-এর মাধ্যমে ফ্রন্টএন্ডের সাথে কানেক্ট করা হবে।
4. **Authentication:** শিক্ষার্থীদের আলাদা আলাদা ড্যাশবোর্ড এবং ডেটা সুরক্ষিত রাখতে NextAuth.js বা Clerk-এর মাধ্যমে ইউজার অথেনটিকেশন (Login/Registration) যুক্ত করা হবে।

> **নোট:** এই ডেভলপমেন্ট ব্রাঞ্চ থেকেই পরবর্তীতে Next.js প্রজেক্ট ইনিশিয়ালাইজ করে ফুল-স্ট্যাক ডেভলপমেন্টের কাজ শুরু করা হবে।
