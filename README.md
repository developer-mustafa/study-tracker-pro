# Academic Board Exam Portal 📚

এটি একটি স্ট্যাটিক সিঙ্গেল-পেজ ওয়েব অ্যাপ, যা শিক্ষার্থীদের সেমিস্টার ট্র্যাকিং এবং পরীক্ষার প্রস্তুতির জন্য তৈরি করা হয়েছে। 

## 🛠 টেকনোলজি এবং ভার্সন

* **Current Version:** `v1.1.0` (Static Frontend)
* **Technologies Used:** 
  * HTML5
  * CSS3 (Custom Variables, CSS Grid/Flexbox)
  * Vanilla JavaScript (ES6+)
  * LocalStorage (for Data Persistence)
  * Boxicons (for Icons)
  * Google Fonts (Hind Siliguri, Inter)

## ✨ বর্তমান অ্যাপের পূর্ণাঙ্গ বৈশিষ্ট্য (Features in v1.1.0)

বর্তমান ভার্সনে নিম্নলিখিত ফিচারগুলো অন্তর্ভুক্ত রয়েছে:

* **সেমিস্টার ট্র্যাকার ও ক্যালেন্ডার:**
  * পড়ার শুরুর তারিখ এবং পরীক্ষার তারিখ সেট করে কাউন্টডাউন দেখার সুবিধা।
  * ক্যালেন্ডার গ্রিডে প্রতিদিনের পড়ার অগ্রগতি দেখা।
* **প্রশ্ন ব্যাংক এবং স্টাডি মোড:**
  * কাস্টম প্রশ্ন (জ্ঞানমূলক এবং MCQ) অ্যাড করার সুবিধা।
  * ডেমো ডেটা লোড করার অপশন, যা এক ক্লিকেই রিমুভ (ফ্রেশ মোড) করা যায়।
  * "পড়ার মোড" - যেখানে জ্ঞানমূলক প্রশ্ন এবং এর উত্তর দেখে পড়া যায়।
* **পরীক্ষা (Exam) মোড ও ফলাফল:**
  * MCQ পরীক্ষা দেওয়া এবং তাৎক্ষণিক সঠিক/ভুল উত্তর যাচাই।
  * পরীক্ষার শেষে স্বয়ংক্রিয়ভাবে গ্রেড ও ফলাফল সেভ হওয়া।
  * "৬০ দিনের স্টাডি রেকর্ড" বোর্ডে পুরোনো পরীক্ষার ও পড়ার হিস্ট্রি দেখা।
* **অ্যাকশন বোর্ড ও ড্যাশবোর্ড:**
  * আজ কতগুলো প্রশ্ন পড়া হয়েছে, কতগুলো সঠিক বা ভুল হয়েছে তার লাইভ স্ট্যাটাস।
  * প্রোফাইল ম্যানেজমেন্ট (নাম এবং শ্রেণি কাস্টমাইজ করা)।
  * ডার্ক মোড এবং লাইট মোড টগল সুবিধা।
  * পোমোডোরো (Pomodoro) টাইমার দিয়ে ফোকাসড পড়াশোনা করা।
* **কাস্টমাইজেশন ও ইউজার এক্সপেরিয়েন্স:**
  * নিজস্ব লেভেল (Level) এবং সাবজেক্ট (Subject) অ্যাড করার সুবিধা।
  * পেজ রিলোড বা ব্লিঙ্ক ছাড়াই মসৃণ ন্যাভিগেশন এবং রেস্পন্সিভ স্ক্রলবার।

## 🚀 আপকামিং ফিচার এবং পরবর্তী ভার্সন (v2.0.0 - Full-Stack Migration)

এই প্রজেক্টটি ভবিষ্যতে **React ও Next.js** ব্যবহার করে একটি সম্পূর্ণ ফুল-স্ট্যাক অ্যাপ্লিকেশনে কনভার্ট করা হবে। পরবর্তী আপডেটে যে ফিচারগুলো আসবে:

* **Next.js Framework:** সম্পূর্ণ প্রজেক্টকে React কম্পোনেন্ট এবং Next.js App Router-এ রূপান্তর।
* **Online Database & Sync:** `localStorage` এর পরিবর্তে ইউজারদের ডেটা সেন্ট্রালি (MongoDB/Firebase/PostgreSQL) সেভ করা হবে, যেন যেকোনো ডিভাইস থেকে অ্যাক্সেস করা যায়।
* **User Authentication:** NextAuth বা Clerk ব্যবহার করে শিক্ষার্থীদের জন্য সিকিউর লগইন ও ড্যাশবোর্ড সিস্টেম।
* **Global Leaderboard:** দেশের অন্যান্য শিক্ষার্থীদের সাথে নিজের র‍্যাংক তুলনা করার লিডারবোর্ড।
* **Advanced State Management:** Redux বা Zustand ব্যবহার করে উন্নত ডেটা হ্যান্ডলিং।
* **TailwindCSS Integration:** কাস্টম CSS থেকে সম্পূর্ণ প্রোজেক্টকে TailwindCSS এ মাইগ্রেট করে আরো সুন্দর ও আধুনিক UI তৈরি।
